# PRD - Plataforma de Gestão para Locadoras de Caçambas

## Visão Geral
Este documento descreve os requisitos funcionais, não funcionais, arquitetura, UX, módulos operacionais, CRM, financeiro, MTR, auditoria, segurança, escalabilidade e critérios de aceite para uma plataforma SaaS completa de gestão de locadoras de caçambas.

## Objetivos
- Centralizar operação.
- Controlar caçambas, obras, clientes e locações.
- Melhorar logística de entregas e retiradas.
- Disponibilizar mapa operacional.
- Gerar indicadores estratégicos.
- Permitir crescimento multiempresa.
